the app:

the goal of the app is to aggregate news for the day from different sources then to look for
patterns and connections between the news, to put them in historical context, and to do material analysis
of the news events to explain how different events connect, what are the underlying factors driving them
are, to project possible future outcomes and tendencies, what their economic and geopolitical impact will be

the app will use an adapter system to provide different sources, it should support web search and rss feeds out of the box
it's configuraiton will live in ~/.config/newsroom

the config can specify default rss feeds to subscribe to

follow up we'll do once the basics work:
the user should also be able to add their own plugins such as adding a source like a telegram bot that will follow telegram channels
then look for news sources based on the feed, and then add them to the list for analysis

the analysis will be generated by an LLM, it should give an overview described above and link to the sources for the claims
to ensure they are grounded, the prompt should live in the config folder for the app so the user can modify

the app should store the news for each day in sqlite, each day summary should contain the links for the sources used
along with a markdown file containing the dialy briefing

the US for the app will be a page in style of wiki or a blog which give the daily briefing, and a sidebar that lets you go through
history or use a datepicker to jump to a specific date
